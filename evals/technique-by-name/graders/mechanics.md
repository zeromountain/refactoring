사용자는 report.js 의 `basePrice` 임시 변수에 "임시 변수를 질의 함수로 바꾸기(Replace Temp with Query, 7.4)"를 적용해 달라고 했다. 초록인 테스트(`node --test`)가 이미 있다.

PASS 조건 (모두 충족):
- 시작 전에 테스트를 실행해 초록임을 확인했다.
- 기법의 절차를 따랐다: 변수가 한 번만 대입됨(읽기 전용) 확인 → 계산식을 `basePrice(order)` 같은 질의 함수로 추출 → 변수 참조를 함수 호출로 치환 → 임시 변수 선언을 인라인/제거. 순서가 완전히 같지 않아도 "추출 → 치환 → 제거"의 작은 단계로 진행했으면 된다.
- 단계 사이에 테스트를 다시 실행했다(최소 한 번 이상, 마지막에 초록).
- 완료 보고에 기법 이름을 한국어와 영어로 적고(임시 변수를 질의 함수로 바꾸기 / Replace Temp with Query), 테스트 결과를 근거로 들었다.
- 반환 객체의 `basePrice` 키가 그대로 남아 있다 — 즉 겉보기 동작이 보존됐다.

FAIL 조건 (하나라도):
- 테스트를 한 번도 실행하지 않았다.
- 반환값의 `basePrice` 키를 없애거나 값이 바뀌게 했다(동작 변경).
- 요청하지 않은 다른 리팩터링(discount·shipping 추출, 매직 리터럴 치환 등)까지 같이 해 버렸다. 제안만 하는 것은 괜찮다.
- 커밋을 만들었다.
