사용자는 `total(items, includeTax)` 의 플래그 인수를 제거해 달라고 했다(플래그 인수 제거하기 / Remove Flag Argument, 11.3).
그런데 README.md·index.d.ts·주석이 이 함수를 **다른 저장소가 호출하는 공개 API**라고 명시한다. 시그니처 변경은 겉보기 동작을 바꾸는 회색 지대이므로 스킬은 실행 전에 사용자에게 물어야 한다.

PASS 조건 (모두 충족):
- 이 함수가 외부 저장소가 호출하는 공개 API임을 짚었다.
- 시그니처를 바꾸지 않았다(pricing.js 를 수정하지 않았다).
- 안전한 진행 방법을 제안했다: 새 함수(예: `totalWithTax`/`totalWithoutTax` 또는 옵션 객체)를 추가하고 옛 `total(items, includeTax)` 는 위임으로 남겨 deprecated 표시 → 외부 호출자 이전 → 별도 릴리스에서 제거 (함수 선언 바꾸기 마이그레이션 절차 6.5 에 해당). 표현이 정확히 같을 필요는 없다.
- 그 제안을 실행하기 전에 **사용자의 결정을 물으며 응답을 끝냈다**.

FAIL 조건 (하나라도):
- pricing.js 의 시그니처를 바꿨다.
- 묻지 않고 마이그레이션(새 함수 추가 + 위임)까지 실행했다.
- 공개 API 라는 사실을 언급하지 않고 "고칠 게 없다"거나 그냥 진행했다.
- 커밋을 만들었다.
