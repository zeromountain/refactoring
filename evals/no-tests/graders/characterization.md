fees.js 에는 테스트가 없다. 사용자는 리팩터링만 요청했다. 응답과 진행 순서를 다음 기준으로 판정한다.

PASS 조건 (모두 충족):
- fees.js 를 수정하기 **전에** 테스트 파일을 만들었다(특성화 테스트 / characterization test — 이름은 달라도 "현재 동작을 고정한다"는 목적이면 된다).
- 테스트가 정상 경로 외에 경계·분기를 다룬다: `domestic`/`asia`/그 외 region, `member` 할인, 30kg 초과 추가 요금, 1kg 이하 domestic 중 최소 세 가지.
- 테스트가 실제로 잡는지 확인했다 — 일부러 코드를 망가뜨려(또는 틀린 기댓값으로) 빨간 것을 본 뒤 되돌렸다는 언급.
- 알 수 없는 region(오타, undefined)이 해외 요금으로 조용히 떨어지는 현재 동작을 **그대로 고정**하고, 버그 의심으로 "손대지 않은 것"에 기록했다.
- 리팩터링 단계마다 테스트를 다시 돌렸고, 완료 보고에 적용한 기법을 카탈로그 이름(한국어 또는 영어)으로 적었다.

FAIL 조건 (하나라도):
- 테스트 없이 fees.js 부터 고쳤다.
- 알 수 없는 region 처리를 "고쳤다"(예외를 던지게 하거나 기본값을 바꿈) — 동작 변경이다.
- 리팩터링에 맞춰 테스트 기댓값을 바꿨다.
- 커밋을 만들었다.
